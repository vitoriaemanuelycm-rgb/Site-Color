## Site-Color
Na aula de Front-end web houve uma atividade avaliativa onde os alunos tinham que criar um site com Bootstrap e Font Awesome. O tema era datas comemorativas de outubro, como Dia do Café, Dia da Música, Halloween, Dia das Crianças, Dia do Pintor, etc. O tema escolhido por mim foi Dia do Pintor, então para a criação houve diversos elementos de artes, como fotos de obras, resumos sobre história da arte e etc.
### Elementos
Foram usados, além das obras, resumos sobre Picasso, história sobre o Dia do Pintor, obra Sunsi, movimentos artísticos como cubismo e impressionismo e etc. Uma lista com os nomes mais famosos da arte, desde artista plástico a grafiteiro e arquiteto, porque a arte não se delimita a um quadro: também é grafite, escultura, arquitetura, desenho no papel e assim por diante.
### Ferramentas
Foi utilizado para a criação o HTML para criar o esqueleto do site, o Bootstrap (que é um framework front-end) para acelerar a criação do site, o Font Awesome (biblioteca de ícones e ferramentas baseadas em CSS e JavaScript que permite adicionar ícones para o desenvolvimento do site). Para o conteúdo foi usada IA e pesquisa, e para as fotos o Pinterest.
### Como Executar
Primeiro, você tem que ter instalado no seu notebook o Git e, no VS Code, a extensão Live Server para funcionar.
Depois disso, é necessário pressionar as teclas Windows + R e digitar powershell para abrir o terminal do Windows. Em seguida, digite cd seguido do caminho da sua pasta (ou arraste a pasta para dentro do terminal).

O próximo passo é digitar git clone <link-do-projeto> (copie o link no botão verde Code do repositório no GitHub). Depois, digite cd <nome-da-pasta-do-projeto>, pressione Enter e digite code . para abrir o projeto no VS Code.
Por fim, basta clicar em Go Live no canto inferior direito para abrir o site no navegador.
